# Quickstart

The quickstart is **`QUICKSTART.md`** at the root of the repository, maintained alongside the `@kigenka/shokai` package and run as written after every change (`tools/verify-quickstart.sh`). The docs site shows it as this page.

[Read the quickstart](../QUICKSTART.md): in about ten minutes, an MCP server behind a Shōkai door, a representative admitted with a pass, a visit that spends within a limit, and the conformance checks.

## Watch an implementation

A film of an implementation sits on this quickstart path. On the docs site it is **Watch the implementation** (`/docs/watch-the-implementation`). It is not part of Verify. Verify is Evidence and the benchmark.
