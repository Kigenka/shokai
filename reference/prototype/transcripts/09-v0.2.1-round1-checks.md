> Short, mechanical visits that exercise each fix from the first round of clean-room testing: a door any newcomer can find, a lobby for any arrival, single-use nonces, explicit answers to out-of-order messages, honest negotiation that is never mistaken for probing, and a language-neutral core.

   - 🔓 Unsigned: Fernwood's representative receives something that isn't a protocol message ("Hi! Can I come in? I'd like to buy a gift."). It doesn't ignore it: it opens the lobby.
   - ⚙️ Machine decision: `GET / → door_pointer (place_listing https://door.example/shokai/places, start_with greeting)`
   - ⚙️ Machine decision: `POST /fernwood (unknown route) → door_pointer`
   - ⚙️ Machine decision: `GET /places → 4 places, each with entry, lobby and onboarding_url`
   - ⚙️ Machine decision: `POST /places/fernwood/entry with plain prose → greeting → lobby_briefing → invitation_response → farewell`
   - The newcomer in round 1 got 404s and gave up. Now every arrival, even a plain sentence or a wrong address, is answered with something a machine can follow.
